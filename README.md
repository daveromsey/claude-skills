# Claude Skills
This is a collection of Claude skills.

## Usage 
1. Clone this repository.
2. Place the contents in `~/.claude/skills/` for personal skills across projects, or `.claude/skills/` inside a repository for project-specific skills.

## Skills
- Update Composer Plugins (`update-composer-plugins`): Updates Composer-managed plugins and generates a report. Also generates a report for non-Composer-managed plugins.
